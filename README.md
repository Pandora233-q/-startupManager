
# Startup Manager - Windows 启动项管理软件

一个基于 Python + Tkinter 开发的 Windows 启动项管理工具，支持统一管理 **注册表启动项**、**系统服务** 和 **计划任务**，提供图形化界面进行启用、禁用（永久）和删除操作。

---

## 功能特性

- **三大来源统一管理**：注册表（Run/RunOnce）、系统服务（sc）、计划任务（schtasks）
- **三种操作**：启用、永久禁用、删除
- **中文名称显示**：自动读取 exe 的 FileDescription 版本信息，显示程序中文名
- **图标提取**：从 exe/dll 文件提取原始图标，服务/任务使用默认标识图标
- **搜索与过滤**：支持关键词搜索 + 按来源类别筛选
- **右键菜单**：快捷操作（禁用/启用/删除/复制命令）
- **权限自动提升**：检测到非管理员运行时，弹窗提示并以管理员身份重启
- **零第三方依赖**：仅使用 Python 标准库（ctypes、winreg、subprocess、tkinter）

## 使用方法

### 直接运行

```
python startup_manager.py
```

### 权限说明

首次运行时，程序会检测当前是否拥有管理员权限：

- **是** → 直接启动主界面
- **否** → 弹出确认框，选择「是」将以管理员身份重新启动；选择「否」则退出

> 以管理员身份运行后，对注册表、服务和计划任务的所有修改才能完全生效。

## 界面操作

| 按钮/操作 | 说明 |
|-----------|------|
| 刷新 | 重新扫描所有启动项 |
| 永久禁用 | 禁用选中的启动项（重启后不恢复） |
| 恢复启用 | 重新启用已禁用的启动项 |
| 删除 | 删除选中的启动项 |
| 打开文件位置 | 打开选中项对应的 exe 所在文件夹 |
| 搜索框 | 按名称/命令/中文名模糊搜索 |
| 来源下拉框 | 按「注册表 / 服务 / 计划任务」筛选 |
| 右键菜单 | 对选中项执行快捷操作 |

## 实现原理

### 架构概览

```
┌─────────────────────────────────────────────┐
│              StartupManagerGUI               │
│  (Tkinter 界面：列表展示 / 搜索 / 操作按钮)   │
└──────────────┬──────────────────────────────┘
               │
┌──────────────▼──────────────────────────────┐
│           OPERATIONS 统一调度器                │
│  {注册表, 服务, 计划任务} -> {list, disable,  │
│                              enable, delete}  │
└──────┬──────────┬──────────┬────────────────┘
       │          │          │
┌──────▼──┐ ┌────▼────┐ ┌───▼────────┐
│ 注册表   │ │  系统服务  │ │  计划任务   │
│ winreg  │ │  sc命令   │ │ schtasks   │
└─────────┘ └──────────┘ └────────────┘
```

### 核心模块

| 模块 | 说明 |
|------|------|
| StartupItem 数据类 | 统一封装启动项信息（名称、命令、来源、状态、中文名、exe路径） |
| 权限检测 | ctypes.windll.shell32.IsUserAnAdmin 检测管理员身份 |
| 图标提取 | 通过 Shell32.ExtractIconExW + GDI32 提取 exe 图标，纯 ctypes 实现 |
| 中文名读取 | 通过 Version.dll.GetFileVersionInfoW 读取 FileDescription 字符串 |
| 注册表管理 | 读写 HKCU/HKLM 的 Run/RunOnce 键，禁用前缀 _disabled_ 标记 |
| 服务管理 | 调用 sc query / sc config / sc delete 管理 Windows 服务 |
| 计划任务管理 | 调用 schtasks /Query /Change /Delete 管理计划任务 |

### 禁用机制

- **注册表**：将键名前加上 _disabled_ 前缀，读取时跳过带前缀的项
- **服务**：调用 `sc config <name> start= disabled`
- **计划任务**：调用 `schtasks /Change /TN <name> /Disable`

---

## 注意事项

1. **管理员权限**：部分操作（尤其是服务和计划任务）需要管理员权限才能执行
2. **系统关键服务**：程序已内置过滤列表（rpcss、csrss、lsass 等），避免误删核心服务
3. **删除操作不可逆**：删除启动项后无法自动恢复，操作前请确认
4. **兼容性**：适用于 Windows 7 及以上版本；64 位系统可同时管理 32 位和 64 位注册表项
5. **图标兼容性**：部分程序可能没有嵌入图标，此时会显示默认标识图标

## 技术栈

- **语言**：Python 3.8+
- **GUI 框架**：tkinter（ttk + Treeview）
- **系统交互**：ctypes（Windows API）、subprocess（sc / schtasks 命令行）
- **注册表**：winreg
- **图标处理**：GDI32 + 纯 Python PNG 编码器（zlib + struct）
